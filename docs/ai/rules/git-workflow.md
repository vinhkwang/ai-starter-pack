# Git workflow

- Never commit to the default branch directly. Work on a branch.
- Branch names: feat/, fix/, chore/, refactor/.
- Conventional Commits with types feat, fix, chore, refactor, docs, test, perf, ci, build and a summary of at most 72 characters.
- One atomic task equals one commit.
- Commit only after verification passes.
- Push right after each commit.
- Forbidden: force push, hard reset, --no-verify, committing secrets or build output.
