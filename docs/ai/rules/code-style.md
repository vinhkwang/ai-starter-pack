# Code style

- No comments of any kind. Express intent through names.
- Functions use verbs, classes use nouns, booleans use is/has/can/should.
- Small, single-purpose functions.
- No magic values. Name constants.
- Early returns over deep nesting.
- Prefer immutability.
- Delete dead code instead of commenting it out.
- Follow the repository formatter and never reformat unrelated code.
